# Design working files

The `.dc.html` files here are the artboards behind the **Snag Home UI** canvas, and
`canvas.json` is its layout. They are the source: changing the published canvas means editing
these and re-seeding, not editing `snag-home-ui.html` (which is a generated bundle).

The rationale for every value in them is `SNAG_DESIGN.md` at the repo root.

Photographs are placeholders — soft tonal SVG blocks standing in for real photos, so the
photo-led layout can be judged without pretending to content that doesn't exist yet.
